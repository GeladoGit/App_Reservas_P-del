# 🎾 Padel Community App

Una aplicación web diseñada para digitalizar y simplificar las reservas de la pista de pádel en una comunidad de vecinos. Este proyecto sustituye el antiguo sistema de apuntarse físicamente en papel, permitiendo a los usuarios reservar cómodamente desde su teléfono móvil en cualquier lugar y momento, democratizando así el acceso a las instalaciones.

### 📖 Sobre el proyecto

Este proyecto nace de una necesidad real: organizar de forma justa y eficiente el uso de una pista de pádel compartida. La aplicación no solo permite reservar franjas horarias, sino que fomenta la comunidad mediante un sistema de "Partidos Abiertos" y notificaciones globales en tiempo real.

### ✨ Características principales

* **Gestión de Reservas:** Sistema de calendario intuitivo para reservar, visualizar y cancelar franjas horarias.
* **Sistema de Login Vecinal:** Acceso personalizado seleccionando el piso y la puerta (ej. Bajo A, 2C).
* **Partidos Abiertos (Matchmaking):** Si una reserva tiene 2 o 3 jugadores, el creador puede marcarla como "abierta". La app busca activamente a los jugadores restantes especificando el nivel requerido.
* **Notificaciones Globales:** Una bandeja de entrada compartida que avisa a todos los vecinos cuando:
  * Alguien crea un partido abierto y necesita jugadores.
  * Se cancela una reserva y queda una pista libre.
  * Se cancela un partido completo.
* **Sincronización en Tiempo Real:** Todos los usuarios ven el estado actual de las pistas en vivo independientemente del dispositivo que usen.

### 🛠️ Tecnologías utilizadas

* **Frontend:** HTML5, CSS3, Vanilla JavaScript.
* **Backend & Base de Datos:** Supabase (PostgreSQL) integrado vía API REST.
* **Despliegue:** Netlify.

### 🚀 Estado del proyecto y Demo

Actualmente, la aplicación se encuentra en **fase de demostración (Demo)**. Mi intención es presentar este proyecto oficialmente en la próxima junta de vecinos para proponer su adopción definitiva en nuestra comunidad.
